Mamba

Mamba programming language and cloud ecosystem

A full-stack, multi-target programming language transpiling single .mb source files into standalone ~80 KB native C++20 machine binaries embedding reactive UI, AI agents, and POSIX/SQLite servers.

v0.4.0 Release · C++20 Transpiler

Schedule an architecture reviewGitHub RepositoryMamba Cloud Gateway

What it does and why.

Mamba unifies modern fragmented web engineering into a single source language. Developed by Muavia Tanveer, Mamba takes declarative reactive UI, stateful business logic, embedded AI agents, and high-performance backend routing in one file, parses via a Lark LALR AST parser, transpiles directly to clean C++20, and compiles via clang++ -O3 into a standalone machine binary requiring zero Node.js or web server runtime dependencies.

The runtime, step by step.

Step 01

Source AST parsing

The Lark LALR parser tokenizes `.mb` syntax, validating state signals, component hierarchies, and agent declarations into a unified AST.

Lark ParserGrammar Grammar.larkAST Builder

Step 02

Dual engine transpilation

Separates declarative UI syntax into an atomic signal bundle while mapping server logic to native C++20 multithreaded handlers.

transpiler_cpp.pyUI Bundle GeneratorRoute Generator

Step 03

Standalone binary compilation

Invokes `clang++ -O3` to compile the generated C++ source with embedded POSIX sockets and SQLite driver into an isolated executable.

clang++POSIX Socket LibrarySQLite3 Static Lib

Step 04

Zero-dependency serving / deploy

Launches the standalone server on a configured port, or pushes via bare Git hooks to mambacloud.app reverse proxy.

mamba devmamba deploymambacloud.app Router
